# Gold & Silver Rate

India-wide daily gold and silver benchmark rates in a compact Chrome extension.

## Project
The extension source is in [gold-silver-rate/](./gold-silver-rate/). It displays 24K, 22K and 18K gold prices, plus silver prices, with an optional estimated 3% GST view.

## Data source
Daily India-wide benchmark snapshots from [Snapdata](https://snapdata.dev/docs/). These are not live intraday prices or city-specific jeweller quotes.

## Install
1. Download and extract the packaged extension ZIP.
2. Open `chrome://extensions`.
3. Enable Developer mode and select **Load unpacked**.
4. Choose the extracted `gold-silver-rate` folder.

## Release
The packaged v1.2.8 ZIP is available in the ChatGPT project handoff. Repository source is maintained in `gold-silver-rate/`.
